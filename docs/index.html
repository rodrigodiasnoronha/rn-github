Política de Privacidade

Última atualização: 18 de outubro de 2026

O aplicativo RN GITHUB (com.rdn.br.rngithub) permite pesquisar perfis e repositórios públicos do GitHub.

Dados coletados

O aplicativo não coleta, não armazena e não compartilha dados pessoais dos usuários. Não há cadastro, login, anúncios, analytics nem rastreadores.

Como o app funciona

O nome de usuário digitado na busca é enviado diretamente à API pública do GitHub (api.github.com) para obter informações públicas do perfil e dos repositórios. Essas informações são exibidas na tela e não são guardadas pelo aplicativo nem enviadas a nenhum servidor do desenvolvedor. O tratamento dos dados pelo GitHub segue a Declaração de Privacidade do GitHub.

Permissões

O aplicativo usa apenas acesso à internet. Ao tocar em "Enviar E-mail" ou em um repositório, ele abre o aplicativo de e-mail ou o navegador do dispositivo.

Crianças

O aplicativo não coleta dados de ninguém, inclusive de menores de idade.

Alterações

Esta política pode ser atualizada; a data no topo indica a última revisão.
